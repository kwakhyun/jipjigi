# 렌트플로우 UX 카피 기준

검토일: 2026-08-30

## 검토 범위

- 공개 랜딩과 지역 가이드
- 로그인, 로딩, 오류, 404 화면
- 오늘의 브리핑, 임대 장부, 계약 관리, 수리 요청, 메시지 센터
- 그로스 관제와 설정
- 모바일 임대 관리 프로토타입의 홈, 장부, 소식, 설정, 상세 화면

`screenshots/before-*.png`에는 수정 전 화면을 감사 근거로 보관한다.

## 문체 원칙

- 사용자의 행동과 결과는 짧은 해요체로 안내한다. 예: `변경 사항을 저장했어요.`
- 기능 설명과 보안 정책은 간결한 합니다체를 사용한다.
- 버튼은 실행 결과를 예측할 수 있는 동사형으로 쓴다. 예: `갱신 의사 확인하기`
- 임대인 화면에서는 내부 개발 용어를 피하고, 그로스 관제처럼 실무자가 보는 화면에만 필요한 기술 용어를 남긴다.
- 계약, 청구, 요청, 메시지는 `건`, 호실은 `개 호실`로 센다.

## 통일한 용어

| 지양하는 표현 | 기본 표현 |
| --- | --- |
| 조용한 시간대, 다음 허용 시각 | 발송 제한 시간, 다음 발송 가능 시간 |
| 가드레일 | 발송 조건 또는 안전 지표 |
| 영속 데이터 | 안전한 데이터 보관 |
| 임대관리, 건물관리 | 임대 관리, 건물 관리 |
| 개 계약 | 건의 계약 또는 건 청구 |
| 임대장부 | 임대 장부 |

그로스 관제에서는 A/B 테스트, Core Web Vitals, HMAC처럼 직무 맥락상 필요한 용어를 유지하되 설명 문장은 한국어로 풀어 쓴다.
