# 버전별 변경 기록

## 2026-09-05: 오류 수정과 접근성 개선

계약, 미납, 수리, 메시지와 실험 관제의 핵심 흐름을 유지하면서 데이터 일관성과 화면 사용성을 개선했습니다.

- 주요 변경 작업에 트랜잭션과 행 잠금을 적용하고, 납부 완료 또는 납기 전 청구의 미납 안내를 차단했습니다.
- 홈의 전체 주의 건수와 대상 세대 수를 정확히 집계하고 전체 목록 링크를 제공했습니다.
- 데이터 접근 모듈을 분리하고 공통 UI를 정리했습니다.
- 모바일 장부, 메시지 날짜 안내, 일정 수정과 검색 결과 안내를 개선했습니다.
- 글자 대비를 조정하고 실제 브라우저에서 색 대비와 200% CSS 확대를 검사했습니다.

두 데모 역할, 브라우저별 12시간 작업공간, 위험 우선안과 일정 우선안은 유지됩니다. 외부 메시지 발송은 샌드박스이며 실제 발송 공급자와 예약 처리 워커는 아직 연결하지 않았습니다. 실험 지표는 데모 기록으로, 실제 고객 성과를 뜻하지 않습니다.
