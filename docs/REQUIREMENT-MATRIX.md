# 채용 요건 대응표

이 문서는 프로젝트가 보여주는 근거와 아직 보완해야 할 부분을 구분합니다. 포트폴리오 프로젝트만으로 실제 근속 기간이나 조직 영향력을 과장하지 않습니다.

## 1. 주요 업무 대응

| 기대 역량 | 프로젝트 근거 | 범위 |
|---|---|---|
| 사용자 경험 개선 | 세 가지 시안을 비교한 뒤 위험 브리핑 중심 화면으로 통합하고, 갱신, 미납, 수리, 입금 확인을 서버 저장까지 연결 | 구현 |
| 프론트엔드로 제품과 사업 확장 | 재방문 브리핑, CRM, 지역 SEO 유입, 실험 관제를 하나의 제품에 연결 | 구현 |
| 새 기술을 제품에 적용 | Next.js App Router, TanStack Query, Jotai, Turborepo, 타입 이벤트, AI 기반 시각 탐색을 실제 산출물로 기록 | 구현 |
| 공통 라이브러리 | `analytics`, `experiments`, `domain`을 workspace 의존성과 공개 API가 있는 패키지로 분리. `ui`는 현재 `cx` 유틸리티 수준 | 도메인 라이브러리 구현, UI 라이브러리는 제한적 |
| 최소 단위 실험 출시 | 위험 우선안과 일정 우선안을 사용자별로 고정 배정하고 실제 렌더 뒤 노출을 기록 | 구현 |
| A/B 테스트와 행동 로그 | 배정, 실제 노출, 서버 보장 행동 완료, 전달 결과와 가드레일 지표를 타입 스키마와 영속 이벤트 테이블에 연결 | 구현 |
| CTA 노출 로직 | 건물 상태와 실험안에 따라 홈 정보 순서를 바꾸고, 발송 전 공통 미리보기로 연결 | 구현 |
| CRM 채널 성장 | 문구 미리보기, 동의, 야간 예약, 목적별 중복 제한, 서버 멱등 키, 전달과 응답 웹훅, 실패 재접수를 구현 | 샌드박스 구현 |
| 신규 재방문 제품 | 계약, 미납, 수리 일정으로 구성한 오늘의 관리 브리핑 | 구현 |
| 광고 수익화 | 수리 비교 견적 문맥형 지면, 빈도 제한, eCPM과 이탈 가드레일을 후속 실험으로 정의 | 설계, SDK 미연동 |
| SEO와 랜딩 전환 | 지역별 서버 렌더링, `generateMetadata`, JSON-LD, robots, sitemap, 전환 CTA를 구현 | 구현, 정적 HTML 산출은 추가 검증 필요 |
| 직군 간 주간 협업 | 실험 회고 템플릿, Definition of Done, 단계별 산출물과 의사결정자를 정의 | 프로세스 설계 |

## 4. 면접에서 정직하게 설명할 부분

- 외부 발송은 샌드박스지만 계약, 청구, 메시지, 감사 로그, 제품 이벤트는 운영에서 Neon Postgres에, 로컬에서 PGlite에 저장됩니다.
- 실험 지표는 정의와 수집 구조까지 준비했지만 실제 트래픽 결과는 없습니다.
- Next.js, TanStack Query, Jotai, Turborepo는 구현했습니다. Panda CSS와 React Native는 아직 구현하지 않았습니다.
- 3년 경력, 조직 문화 변화, 실제 매출 개선은 별도의 경력 사례가 있어야 주장할 수 있습니다.

## 5. 가장 효과적인 보완 순서

현재 우선순위는 기능 수를 늘리기보다 평가자가 재현하고 근거를 확인할 수 있는 상태를 만드는 것입니다.

1. **개인 데모와 날짜 독립성:** 브라우저별 데이터 격리, 상대 날짜, 본인 초기화와 두 홈 구성 재현을 구현했습니다. [검증 사례](case-studies/demo-reproducibility.md)를 확인합니다.
2. **실제 웹앱 E2E:** 계약에서 메시지 접수, 저장 유지, 역할 전환, 방문자 격리와 모바일 탐색을 포함한 4개 시나리오가 로컬에서 통과했습니다. [실행 기록](E2E.md)을 확인하고, 커밋 후 CI에서도 재현되는지 확인한 뒤 제출합니다.
3. **설명과 증거:** README 체험 순서, 코드 선택 이유와 AI 활용 기록을 보강하고 최신 빌드의 실제 화면으로 교체했습니다. 공개 제출 전에는 제출할 커밋의 CI 통과와 배포 SHA 일치를 확인합니다.
4. **실제 사용성 관찰:** 동의받은 임대인 또는 유사 경험자에게 핵심 과제를 관찰하고 문제, 개선, 재검증을 기록합니다. 수행 전인 [관찰 계획](USER-VALIDATION.md)을 성과로 표기하지 않습니다.

그다음에는 반복 사용할 UI 컴포넌트의 공개 API와 접근성 테스트를 보강합니다. 실제 사용자와 공급자 연동 필요성이 생기면 인증, 예약 워커, 오류 추적과 운영 경보를 우선하고 React Native 한 흐름을 검토합니다. 광고 SDK는 도메인 가치와 가드레일을 확인한 뒤의 후속 작업입니다.
