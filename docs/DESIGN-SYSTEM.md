# 렌트플로우 디자인 시스템

## 1. 시각 방향

신뢰가 필요한 임대 운영 도구이므로 과장된 대시보드보다 명확한 한 가지 행동, 충분한 여백, 근거가 보이는 상태 표현을 우선합니다. 야간 건물 헤더는 하루를 마감하거나 다음 일을 준비하는 관리 브리핑의 성격을 전달합니다.

## 2. 의미 토큰

| 역할 | 프로토타입 값 | 용도 |
|---|---|---|
| `surface.canvas` | `#fcfbfd` | 기본 배경 |
| `surface.night` | `#0e0a2a` | 브리핑 헤더 |
| `text.primary` | `#1c1b27` | 제목과 본문 |
| `text.muted` | `#6f6c7a` | 보조 설명 |
| `action.primary` | `#7357f6` | 주 행동 |
| `status.risk` | `#ef655f` | 확인이 필요한 단일 위험 |
| `status.stable` | `#168452` | 안정, 완료, 수납 |
| `border.subtle` | `#e9e7ee` | 목록 구분선 |

프로덕션 Panda CSS에서는 원시 색을 기능 컴포넌트에서 직접 사용하지 않고 위 의미 토큰만 참조합니다.

## 3. 타이포그래피

- 한글 기본: Pretendard Variable 또는 검토된 동급 로컬 폰트
- 숫자는 tabular figure를 지원하는 설정을 우선합니다.
- 본문은 14~16px를 기본으로 하며 12px 아래 텍스트는 법적 보조 설명처럼 제한된 경우에만 사용합니다.
- 위험 숫자와 금액은 크기뿐 아니라 문맥 레이블을 함께 제공합니다.

## 4. 간격과 형태

- 기본 간격 단위: 4px
- 화면 좌우 여백: 모바일 22~24px
- 터치 영역: 최소 44px
- 주 버튼 높이: 52px
- 바텀시트 모서리: 24px
- 일반 컨트롤 모서리: 12~16px

카드 안에 카드를 넣지 않습니다. 목록은 여백과 얇은 구분선으로 먼저 묶고, 표면 색과 그림자는 필요한 경우에만 사용합니다.

## 5. 핵심 컴포넌트

### DailyBriefing

- 헤더, 현재 건물, 우선 위험, 안정 메시지로 구성합니다.
- 위험은 한 건만 펼치고 나머지는 접습니다.
- 확률 대신 날짜, 최근 기록, 상태 같은 근거를 사용합니다.

### RiskCard

- 상태 아이콘, 제목, 근거 요약, 주 행동을 가집니다.
- coral 색상만으로 위험을 표현하지 않고 `확인 필요` 문구를 함께 둡니다.

### TimelineRow

- 시각, 상태 표식, 작업 제목, 보조 행동 순서입니다.
- 행 전체가 하나의 44px 이상 버튼입니다.

### MessagePreviewSheet

- 발송 대상의 마스킹된 식별, 문구, 채널, 동의, 야간 제한, 발송 버튼을 포함합니다.
- 발송 중, 성공, 실패, 중복 차단 상태가 필요합니다.

## 6. 상호작용 상태

| 상태 | 표현 |
|---|---|
| 기본 | 높은 대비의 텍스트와 명확한 행동 레이블 |
| 누름 | 색을 한 단계 진하게 변경 |
| 키보드 포커스 | 3px 고대비 외곽선 |
| 로딩 | 아이콘과 `보내는 중` 문구, 중복 탭 방지 |
| 성공 | 체크 아이콘, 결과 문장, 홈 상태 갱신 |
| 오류 | 원인과 재시도 가능 여부를 함께 설명 |
| 비활성 | 이유를 인접 문장으로 제공 |

## 7. 접근성 체크

- 아이콘 전용 버튼은 `aria-label`을 가집니다.
- 바텀시트 제목과 설명이 스크린리더에 연결됩니다.
- 성공 토스트는 `role=status`와 `aria-live=polite`를 사용합니다.
- 상태는 색, 아이콘, 텍스트 중 두 가지 이상으로 전달합니다.
- 모션 감소 설정에서는 회전과 전환을 제거합니다.
- iPhone 393px과 Pixel 427px에서 텍스트 확대와 잘림을 점검합니다.
